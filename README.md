# Opiki (오피키)

> 여러 사이트를 돌아다니며 청년 혜택을 찾다가 복잡한 신청 과정에 지쳐 포기했던 경험을 해결하기 위한, **AI 기반 청년 혜택 통합 추천/관리 플랫폼**입니다.

## 소개

Opiki는 나이·소득·학력·거주지 등 사용자 정보를 바탕으로 AI가 실제로 신청 가능한 혜택만 추천하고, 신청 일정을 캘린더와 푸시 알림으로 관리해주는 서비스입니다.

- 혜택 = 기회(opportunity), 기회 → 열쇠(key) → **Opiki**

## 주요 기능

| 기능 | 설명 |
|---|---|
| 혜택 상세/요약 | 공고 원문을 AI가 핵심만 요약해서 보여줍니다 |
| 맞춤형 혜택 추천 | 로그인 시 사용자 정보 기반으로 실제 신청 가능한 혜택만 추천합니다 |
| 스크랩(즐겨찾기) | 관심 혜택 저장, 중복 지원 불가 혜택은 AI가 비교 안내합니다 |
| AI 혜택 비교 추천 | K패스처럼 조건별 방식이 다른 혜택을 비교 분석해줍니다 |
| 캘린더 | 스크랩한 혜택의 신청기간을 월간 뷰/마감임박순으로 보여줍니다 |
| 푸시 알림 | 신청 시작/마감, 신규 혜택 등록 시 알림을 보냅니다 |
| AI 상담원 | 대화형으로 상황에 맞는 혜택을 추천받습니다 |
| 최근 본 공고 | 최근에 조회한 공고를 다시 확인할 수 있습니다 |

> 참고: 기획 단계에서 검토했던 "소비기록 기반 카드 추천" 기능은 구현 제약(타 앱 알림 읽기 불가, 마이데이터 라이선스 필요)으로 범위에서 제외했습니다.

## 기술 스택

- **Frontend**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4
- **State**: Zustand
- **Routing**: React Router
- **Icons**: lucide-react
- **현재 단계**: 프론트엔드 + 목업 데이터 기반 데모 (백엔드 연동 전)
- **배포 계획**: 웹앱으로 개발 후 추후 Android 패키징 예정 (Capacitor 등 검토)

## 폴더 구조

```
src/
├── components/
│   ├── layout/     # Header, BottomNav, AppLayout
│   └── ui/         # BenefitCard, StatusBadge 등 공통 컴포넌트
├── pages/          # 화면 단위 페이지
├── mocks/          # 목업 데이터 (혜택, 사용자, 알림)
├── store/          # Zustand 전역 상태 (인증, 스크랩, 최근 본 공고)
└── types/          # 공용 타입 정의
```

## 시작하기

```bash
npm install
npm run dev      # 개발 서버 실행
npm run build    # 프로덕션 빌드
```
