## 3. 다음 작업자가 알아야 할 것

- **로그인 상태는 현재 `useAuthStore.login()`을 호출해야만 바뀝니다.** 실제 로그인 화면(Login.tsx)은 아직 목업 버튼도 없는 빈 화면이니, 다음 단계에서 "로그인" 버튼 클릭 시 `login()`을 호출하도록 연결해야 합니다.
- **혜택 목업 데이터(`src/mocks/benefits.ts`)는 Figma 화면에 나온 값(청년 교통비 지원사업, 국가근로장학금 등)을 그대로 반영**했습니다. 화면 추가 시 이 데이터를 최대한 재사용하세요.
- **디자인 토큰은 `src/index.css`의 `@theme`에만 정의**되어 있고, Tailwind 설정 파일(`tailwind.config.js`)은 v4 방식이라 별도로 존재하지 않습니다. 색상 추가/수정 시 여기를 고치면 됩니다.
- **중복 지원 불가 혜택 비교 로직**은 `mocks/benefits.ts`의 `mockComparisonGroups`에 그룹 데이터만 만들어뒀고, 실제 UI/로직 연결은 아직 안 했습니다 (즐겨찾기 화면 구현 시 필요).
- **아직 백엔드 연동 없음** — 사용자가 "지금은 프론트엔드 위주, 목업데이터로 데모"를 선택했기 때문에, API 명세서(`docs/planning/04_API_명세서.md`)는 참고용이며 실제 fetch 호출은 없습니다.
- **Android 패키징은 아직 착수 전**입니다. 반응형 기준은 `max-width: 480px` 중앙 정렬(`app-shell` 클래스)로 모바일 뷰만 고려되어 있습니다.
