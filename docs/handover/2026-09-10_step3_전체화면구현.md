## 1. 이번 작업에서 한 일

### 로그인 (`/login`)
- 아이디/비밀번호 입력 필드, 소셜 로그인 버튼(네이버/구글/전화번호) — **모두 클릭 시 목업 로그인 처리**(`useAuthStore.login()`)
- "회원가입 하기" → `/onboarding`으로 이동

### 온보딩 (`/onboarding`)
- 닉네임/성명/나이/거주지/상세주소/소득분위/학력/학교/전공/취업여부/특화분야 입력 폼
- 필수값(닉네임/성명/거주지) 미입력 시 저장 버튼 비활성화
- "다음에 입력할게요" → 스킵 확인 모달("선택 정보를 입력하지 않고 건너뛰시겠습니까?") → 확인 시 최소 정보로 온보딩 완료 처리

### 프로필 (`/profile`)
- 비로그인 시 로그인 유도 화면
- 로그인 시 내 상황 요약 카드, 관리 메뉴(내 정보/추천 기준), 로그아웃 버튼

### 즐겨찾기 (`/scraps`)
- 내 상황 요약 카드 (프로필 연동)
- AI 추천 혜택 TOP3 (목업: `viewCount` 내림차순 — 실제 추천 알고리즘 아님)
- **중복 지원 불가 혜택 비교 배너 실동작**: 같은 `comparisonGroupId`를 가진 혜택이 **2개 이상 스크랩**되어야 배너가 뜨도록 구현 (Step 2에서 남긴 TODO 해결)
  - 목업 데이터에 `청년도약계좌`(b-006) / `청년미래적금`(b-007) 추가해서 테스트 가능하게 함
  - 추천 로직은 `src/utils/recommend.ts`에 규칙 기반(거주지역 매칭)으로 임시 구현 — **실제 AI 분석 아님**
- 즐겨찾은 혜택 목록 + 빈 상태 UI

### 캘린더 (`/calendar`)
- 월간 캘린더 그리드 (이전/다음 달 이동), 스크랩한 혜택의 신청 시작/마감일에 점(dot) 표시
- 마감임박순 리스트 (D-day 뱃지)
- **주의**: "오늘" 날짜를 실제 시스템 날짜가 아니라 **`2026-05-19`로 하드코딩**했습니다 (Figma 예시 데이터가 2026년 5월 기준이라 D-day 표시가 맞도록 맞춤). 실제 서비스 배포 시 `new Date()`로 교체 필요합니다 — `src/pages/Calendar.tsx`의 `calcDDay` 함수 및 `todayKey` 변수 확인하세요.

### 알림 내역 (`/notifications`)
- 전체/마감임박/공지 탭 필터링, 목업 알림 4건(`src/mocks/user.ts`) 표시

### 최근 본 공고 (`/recent`)
- 혜택 상세 진입 시 자동 기록된 목록 표시 (빈 상태 포함)

### AI 상담원 (`/ai`)
- 채팅 UI, 키워드 매칭 기반 목업 응답 (교통/저축/장학금/취업 키워드 인식 → 관련 혜택 카드 인라인 추천)
- **실제 GPT API 연동 아님** — `src/pages/AIChat.tsx`의 `getMockReply` 함수 상단에 TODO 남김

### 비교하기 (`/benefits/:id/compare`)
- K패스(b-005) 대상으로 조건별 옵션(일반/청년/저소득층) 비교 UI 구현
- 프로필 나이 기반으로 AI 추천 옵션 하이라이트 (규칙 기반 목업)

### 기타
- `src/index.css`에 공용 `.input` 클래스 추가 (로그인/온보딩/AI상담원 입력창에서 공용 사용)
- `npx tsc -b`, `npm run build` 통과 확인

## 2. 아직 안 한 일 / 알려진 한계

| 항목 | 내용 |
|---|---|
| 실제 인증 | 로그인은 입력값 검증 없이 아무 값이나 넣고 눌러도 통과됩니다 (데모 목적) |
| 실제 AI 로직 | 요약(Step2), AI 상담원, 혜택 비교, AI 추천 TOP3 — **전부 규칙/키워드 기반 목업**입니다. 실제 AI API 연동은 미착수 |
| 캘린더 "오늘" 날짜 | `2026-05-19`로 하드코딩됨 (위 설명 참고) — 배포 전 수정 필수 |
| 알림 발송 | 푸시 알림 자체(FCM 등)는 구현 안 됨. `/notifications`는 정적 목업 리스트만 보여줌 |
| 반응형/접근성 | 모바일(max-width 480px) 기준으로만 작업, 키보드 포커스 스타일 등 접근성 디테일은 미흡 |
| 기본 캘린더 앱 연동 | `.ics` export 등 실제 OS 캘린더 연동 기능은 미구현 (PRD P2 항목) |
