# Opiki 제품요구사항정의서 (PRD)

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | Opiki |
| 한 줄 정의 | AI가 사용자 맞춤 청년 혜택을 추천하고 신청 일정까지 관리해주는 청년 혜택 통합 플랫폼 |
| 배경/문제정의 | 청년 혜택 정보가 여러 사이트에 분산되어 있고, 신청 과정이 복잡해 정보 탐색 중 포기하는 사용자가 많음 |
| 목표 | (1) 혜택 정보를 한 곳에서 탐색 가능하게 통합 (2) AI로 개인화된 혜택 추천 (3) 신청 일정을 놓치지 않도록 관리 |
| 타겟 사용자 | 국가/지자체 청년 지원 혜택 대상이 되는 만 19~39세 청년 (소득/학력/거주지 등 조건이 다양한 사용자) |

## 2. 핵심 가치 제안 (Value Proposition)

- 혜택 탐색 시간 단축 (여러 사이트 → 1개 플랫폼)
- 자격 조건에 맞지 않는 혜택은 걸러내는 AI 맞춤 추천
- 신청 마감을 놓치지 않는 캘린더 + 푸시 알림
- 긴 공고문을 AI가 요약해 이해 부담 감소

## 4. 기능 상세 정의

### 4.1 혜택 상세/요약
- 사용자가 공고 클릭 시 상세 내용 표시
- "상세/요약" 토글 버튼 → AI가 원문을 핵심만 요약해 재구성
- 요약 결과는 캐싱하여 동일 공고 재요청 시 API 재호출 최소화 권장

### 4.2 인기 혜택 TOP3 배너 (비로그인)
- 클릭/스크랩/조회 수 등 지표 기반으로 AI 또는 배치 로직이 TOP3 산정
- 로그인 없이도 노출, 개인화 없음(전체 사용자 공통 노출)

### 4.3 맞춤형 혜택 추천 (로그인 후)
- 입력 정보: 나이, 소득, 학교(재학/졸업 등), 거주지 등
- AI가 신청 자격요건과 매칭하여 "실제 신청 가능한" 혜택만 필터링 후 추천
- 신뢰도를 위해 추천 근거(예: "만 29세 이하, 서울 거주 조건 충족") 함께 제공 권장

### 4.4 스크랩(즐겨찾기)
- 공고 우측 즐겨찾기 버튼 클릭 시 저장
- 스크랩 전용 목록 화면 제공
- 중복 지원 불가 혜택(예: 청년도약계좌 vs 청년미래적금) 스크랩 시, AI가 사용자 정보 기반으로 더 유리한 혜택을 비교해 안내

### 4.5 AI 혜택 비교 추천
- 하나의 혜택이라도 조건에 따라 방식이 갈리는 경우(예: K패스) 상세 화면 내 "비교하기" 버튼 제공
- 사용자 정보 입력값 기반으로 AI가 유리한 옵션을 분석해 제시

### 4.6 캘린더
- 스크랩한 혜택의 신청 기간을 달력 뷰로 시각화
- 마감 임박순 정렬 리스트 뷰 병행 제공
- 휴대폰 기본 캘린더 앱과 연동(iOS: EventKit / Android: CalendarContract, 또는 .ics 파일 내보내기 방식)

### 4.7 푸시 알림
- 트리거: 신청 가능일 도래, 신청 마감 임박(D-day 설정), 신규 혜택 등록
- 인앱 알림 센터에서 과거 알림 재확인 가능
- FCM(Firebase Cloud Messaging) 기반 구현 권장

### 4.8 AI 상담원
- GPT 기반 대화형 UI
- 사용자의 발화(관심사, 상황)를 분석하여 관련 혜택 우선 추천
- 예: "대중교통 자주 이용" → 교통비 지원 혜택 우선 노출

### 4.9 최근 본 공고 기록
- 사용자별 최근 조회 공고 리스트 (로그인 사용자 대상)

## 6. 성공 지표 (제안)

- 맞춤 추천 클릭률(CTR)
- 스크랩 → 실제 신청 전환율(가능 시 외부 링크 클릭으로 근사 측정)
- 푸시 알림 통한 재방문율
- 신규 가입자 중 온보딩(나이/소득/학교/거주지 입력) 완료율
