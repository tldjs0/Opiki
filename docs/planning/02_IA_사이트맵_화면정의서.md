# Opiki IA (정보구조) & 화면정의서

## 1. 사이트맵

```
Opiki
├── 홈 (메인)
│   ├── 인기 혜택 TOP3 배너 (비로그인/로그인 공통)
│   └── 맞춤 혜택 추천 리스트 (로그인 시)
├── 혜택 탐색
│   ├── 카테고리/필터 (지역, 분야, 대상 등)
│   ├── 검색
│   └── 혜택 목록
├── 혜택 상세
│   ├── 상세 보기 / 요약 보기 (토글)
│   ├── 비교하기 (조건부 노출)
│   └── 즐겨찾기(스크랩) 버튼
├── 스크랩(즐겨찾기)
│   └── 저장 혜택 목록 + 비교 안내(중복 불가 혜택)
├── 캘린더
│   ├── 월간 뷰 (신청기간 시각화)
│   ├── 마감 임박순 리스트 뷰
│   └── 기본 캘린더 앱 연동 설정
├── AI 상담원 (챗봇)
│   └── 대화형 추천
├── 알림
│   └── 알림 히스토리
├── 마이페이지
│   ├── 회원정보 (나이/소득/학교/거주지)
│   ├── 최근 본 공고
│   └── (보류) 소비 카테고리 설정
└── 로그인/회원가입
    └── 온보딩 (프로필 입력)
```

## 2. 사용자 플로우 (핵심 시나리오)

### 2.1 신규 사용자 — 가입 후 첫 추천까지
```
앱 실행 → 홈(비로그인, TOP3 배너 확인)
     → 회원가입/로그인
     → 온보딩(나이/소득/학교/거주지 입력)
     → 홈(로그인, 맞춤 추천 리스트 노출)
     → 혜택 상세 진입 → 요약 보기 전환
     → 스크랩
     → 캘린더에 자동 반영 확인
```

### 2.2 중복 불가 혜택 스크랩 플로우
```
혜택A 스크랩 → 혜택B(중복불가 대상) 스크랩 시도
     → AI가 사용자 정보 기반 비교 안내 노출
     → 더 유리한 혜택 선택 유도
```

### 2.3 조건별 방식이 다른 혜택 비교 플로우 (예: K패스)
```
혜택 상세 진입 → "비교하기" 버튼 클릭
     → 사용자 정보 기반 AI 분석
     → 유리한 옵션 결과 제시
```

### 2.4 알림 → 신청 플로우
```
푸시 알림 수신(마감 임박) → 알림 탭
     → 해당 혜택 상세 화면 이동
     → 외부 신청 링크 이동
```

## 4. 화면별 상태(States) 참고사항

- **S-01 홈**: 비로그인 상태 / 로그인+온보딩 미완료 / 로그인+온보딩 완료, 3가지 상태 분기 필요
- **S-03 혜택 상세**: 상세 뷰 ↔ 요약 뷰는 클라이언트 토글이지만 요약 텍스트는 서버(AI)에서 최초 1회 생성 후 캐싱 권장
- **S-04 스크랩 목록**: 빈 상태(스크랩 없음) UI 별도 필요
- **S-06 비교 결과**: 비교 대상 혜택이 명확히 정의된 경우에만 진입 가능 (모든 혜택에 노출 X)
